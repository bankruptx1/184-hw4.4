# STAT 184 HW 4.4

This repository contains my reproducible data analysis project from HW #4.3, completed using R and Quarto.

## Project Overview

The project includes descriptive statistics for diamonds, a basketball scoring visualization, Monte Carlo integration, and a calcium study comparing two visualization approaches.

## Data Sources

I used the diamonds dataset from ggplot2, games.csv, and calcium.csv. The instructor also provided chatgptPlot.png for comparison.

## Plan

My goal was to organize my previous analysis into a reproducible Quarto report and use GitHub to manage changes. The more detailed project plan is included in plan.md.
